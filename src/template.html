Self-study-Vokabeln für den Test

Jetzt aktualisieren

Der Download startet im Browser. Danach die Benachrichtigung „Download abgeschlossen“ antippen und „Aktualisieren“ wählen – dein Lernstand bleibt erhalten. Beim ersten Mal fragt Android, ob der Browser Apps installieren darf.

Prüfungssimulation 30 zufällige Vokabeln als englische Lückensätze. Die Auswertung kommt erst am Ende.

Fehlerprotokoll

Noch keine Fehler

Jeder Fehler aus Schreiben, Prüfung und Karteikarten („Nochmal“) wird mit deiner Antwort gespeichert – auf allen gekoppelten Geräten gemeinsam. Zum Auswerten einfach kopieren und Claude schicken.

Geräte-Sync

1. Auf dem ersten Gerät

Der Lernstand wird verschlüsselt in einem geheimen Gist in deinem GitHub-Konto gespeichert. Dafür einmal einen Token erstellen, der nur Gists bearbeiten darf:

  1. Token-Seite bei GitHub öffnen (Berechtigung „gist“ ist schon ausgewählt)
  2. Ablaufdatum wählen, z. B. 90 Tage, unten auf „Generate token“ tippen
  3. Den Token (beginnt mit ghp_) kopieren und hier einfügen
oder

2. Auf dem anderen Gerät

Kopplungscode vom ersten Gerät einfügen. Beide Lernstände werden zusammengeführt – ein Token ist hier nicht nötig.

Verbunden

Weiteres Gerät verbinden

Diesen Code auf dem anderen Gerät unter Geräte-Sync → Verbinden einfügen. Er enthält den Schlüssel und deinen Token – nur an dich selbst schicken.

Abgleich automatisch beim Öffnen und ein paar Sekunden nach jeder Antwort. Ende-zu-Ende-verschlüsselt (AES-GCM): Auch GitHub sieht nur unlesbare Daten.
